## ❓ FAQ

### Do I need to run it as Administrator?

No. This repository is an informational reference and does not contain software that needs to be launched.

### Which scripting language does Civilization VI use?

Lua is used for gameplay and interface scripting. XML and SQL are also used to define and modify game data.

### What is the purpose of a modinfo file?

A modinfo manifest describes a mod and identifies its content files and actions, allowing Civilization VI to load the registered components.

### Which tools are used to develop Civilization VI scripts?

The official development tools include ModBuddy and FireTuner. ModBuddy supports project development, while FireTuner provides runtime debugging and inspection.

### Can scripts change gameplay mechanics?

Yes. Properly configured mods can use Lua, XML, and SQL to customize supported game behavior and data. This reference itself does not contain ready-to-run scripts.
